# Sistema Solar

Experiencia visual interativa do sistema solar, feita com HTML, JavaScript e SCSS compilado para CSS. O projeto e estatico e pode ser publicado diretamente no GitHub Pages.

Os arquivos de estilo ficam em `styles/` e os arquivos JavaScript ficam em `js/`.

## Desenvolvimento

```bash
npm install
npm run build:css
```

Abra `index.html` no navegador para testar. Durante a edicao de estilos, use `npm run watch:css`.
